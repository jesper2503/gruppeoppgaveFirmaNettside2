InstaKG Support

How can we help?

Welcome to InstaKG support!

InstaKG is a small indie project. This page covers a few common issues and explains how to get in touch if something is not working as expected.

Before contacting support, try refreshing the page and checking that you are using the latest version of the project.

Frequently asked questions

My profile picture or post image is not showing.

Check that the image is inside the assets folder and that its filename and capitalization exactly match the path used in the project. Then refresh the page.

My likes, comments or messages disappeared.

InstaKG saves this information in your browser's localStorage. It is normally kept when you refresh the page, but it may be lost if you clear site data, use a different browser, or open the project in a different browser profile.

A bot is not replying.

Bot replies are scripted and randomized, so they may take a moment to appear. Check that JavaScript is enabled and that the browser console does not show a missing-file error.

A button or page is not working.

Refresh the page first. If the problem continues, check that the relevant HTML, CSS and JavaScript files are in their expected folders and that their filenames are spelled correctly.

The website looks strange on my phone.

Try refreshing the page and using an up-to-date browser. If the layout is still broken, include your device and browser information when contacting support.
