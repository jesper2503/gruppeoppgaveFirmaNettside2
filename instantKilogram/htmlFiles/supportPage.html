InstaKG Support

How can we help?

Welcome to InstaKG support!

InstaKG is a small indie project. This page covers a few common issues and explains how to get in touch if something is not working as expected.

Before contacting support, try refreshing the page and checking that you are using the latest version of the project.

Frequently asked questions

My profile picture or post image is not showing.

If you’re not able to select a profile picture, make sure that the picture you wish to use fits our formatting, (500 x 500 pixels) and is no larger than 5mb, as for publishing posts on you page, make sure the picture is no larger than 1mb.

My likes, comments or messages disappeared.

InstaKG saves this information in your browser's localStorage. It is normally kept when you refresh the page, but it will be lost if you clear your search history. If that is not the case, try to open our website in a different browser.

A bot is not replying.

Bot replies are scripted and randomized, it is normal for them to take a moment to appear. If they don’t show at all try to refresh the website, if the issue is still consistent please contact our administrator. Contact information is listed below.

The website looks strange on my phone.

Try refreshing the page and using an up-to-date browser. If the layout is still broken, include your device and browser information when contacting support.
